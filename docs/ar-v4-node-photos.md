# V4 路網節點照片預覽

在工作台選擇場域與樓層，開啟「路網編輯」，點選 AR 點位或路徑節點；照片區直接讀取該節點已保存的 V4 參考照片。

- 環景批次優先顯示最新一批，預設選取環景 0°；用角度按鈕切換其餘方向。有多批資料時可切換照片組。
- 「環景 0°」表示拆解環景的中央視角，不一定是地圖 0°。例如 Geox 大門這批環景的 0° 照片，已校正成地圖 9°，兩個角度會分開標示。
- 照片切換只改變預覽，不改寫照片、角度、辨識設定或路網，不需要按保存。
- 「舊版主圖（上傳／更換）」保留原有單張主圖操作，與 V4 八方向預覽分開；上傳或移除舊主圖仍屬資料編輯，需要保存。
- 沒有環景資料的節點不會借用其他節點的照片，也不會把一般照片假裝成八方向。未保存的採集草稿請先在照片採集流程完成保存。

此功能只在 V4 工作台路網編輯器啟用。V3 民眾端與照片欄位不改動；V4 民眾端仍只載入辨識特徵包，不因這項工作台預覽改為下載八張參考照片。
