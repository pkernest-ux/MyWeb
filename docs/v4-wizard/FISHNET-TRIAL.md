# V4 Fishnet 試驗操作與驗證

本試驗在既有 V4 局部影像辨識上加入格網索引與診斷。格網把影像特徵分配到可追溯的 cell ID；只有具有效環景批次及取景 metadata 的照片，才會進一步對應到同一環景的 UV／方向格。

它仍是影像／方向索引，不是精確 XYZ 定位、手機姿態求解、世界錨定或行走測距。辨識成功不代表人已抵達，也不會自動更新導航位置。試驗不購買或接入 VPS，不修改 V3；本機建置、測試通過均不代表已發布到正式站。

## 用同一張測試照比較兩種模式

本機試驗入口為 `http://127.0.0.1:8081/ar-v4-field.html?v=fishnet-20260907`，可用 `npm run preview:ar-v4-fishnet` 啟動。首次讀取會以專案內 `ar-data.json` 建立 `.local/ar-v4-fishnet/` 獨立副本，之後保留該副本的修改；不會覆蓋原有 `.local/ar-v4/` 或雲端資料。若來源後續更新，需人工確認同步方式，不會自動蓋過試驗資料。

1. 在 V4 工作台選好場域、樓層及節點，進入「相機測試 → 照片定位測試」。
2. 使用「匯入測試照」選擇一張尚未加入參考資料的照片。這個入口只做辨識，不會保存成節點照片，也不會要求相機或方向權限。
3. 在預設的「Fishnet 試驗」查看結果；可展開「辨識診斷」查看候選、有效配對及格網。
4. 切換「原版對照」，再按「重跑這張測試照」。切換會清空上一模式的候選與診斷，但保留同一張測試照。不要重拍或換圖，才能比較同一輸入。
5. 可再切回「Fishnet 試驗」並重跑。記錄兩模式的候選節點、拒絕原因、配對／幾何有效點數；特徵數較多不等於定位較準。

真實現場比較應保留未入庫的正例與反例，涵蓋另一手機、距離、轉角、光線及遮擋；不要把參考照片自身匹配當作現場準確率。

## 看懂格網與參考特徵

- 展開 Fishnet 診斷後，用「查看 Fishnet 參考」選擇參考項目；「顯示 Fishnet 格線」控制格線。
- 點選一格、用鍵盤移至該格並啟動，或使用「選取參考格」下拉選單，可查看該格特徵與配對資訊；展開「格 ID 與參考方向」可讀取完整 cell ID。格子表示影像區域，不是地圖上的實體位置。
- 「只顯示特徵參數」呈現不含原照片的參考特徵圖。格線、點位與匹配區域可協助檢查分布，但無法取代人工核對現場。
- 淡色的展示點每張最多取樣 96 個，降低診斷畫面的記憶體負擔；格內特徵數、辨識描述子和實際匹配點仍使用完整資料。展示點不是全部特徵，也不是精度百分比。
- 有效環景 metadata 包含同一批次識別、yaw、pitch、FOV 等。0° 與 360° 是同一環景接縫方向；重疊取景應指向同一環景座標系，不因此變成不同位置。
- 缺少有效批次／取景 metadata 的舊照片仍可辨識，但只顯示 image-only 格網。即使有人工填寫的照片方向，也不能反推完整環景 UV 或相機 XYZ。

## 民眾端

在 AR 導引內展開「辨識診斷與搜尋範圍」，可切換 Fishnet／原版對照並查看診斷。民眾端使用發布時建立的二進位特徵包；參考特徵圖來自包內的特徵參數，不下載參考原照片。顯示特徵參數不代表特徵包完全不含場景資訊，分享與發布仍須遵守場域資料規則。

原版及 Fishnet 分別使用自己的特徵包；切換後需載入相容的索引，不以錯誤版本替代。特徵包缺漏／失敗應提示原因及重試，不回退下載照片。相機與方向感測仍須使用者明確啟動；抵達仍由使用者確認。

## 自動化驗證

新增的瀏覽器測試入口：

```sh
cd /Volumes/MyPassport/MyWeb-v3
node test/ar-v4-fishnet-browser.mjs
```

測試使用現有 Playwright 與本機 Chrome，先建立合成影像及獨立暫存資料，再啟動隨機 loopback 埠。它不使用新現場照片、不寫入真實 `ar-data.json` 或 `.local/ar-v4`，也不發送後台修改請求。測試可用 `AR_V4_TEST_PLAYWRIGHT` 與 `AR_V4_TEST_CHROME` 指定既有安裝；瀏覽器啟動被環境阻擋時應回報，不停用安全限制繞過。

2026-09-07 本機 Chrome 瀏覽器測試已通過以下項目：

| 項目 | 證據 |
| --- | --- |
| 同圖 A/B | 同一未入庫裁切圖切換兩種模式；送入 worker 的影像尺寸與像素摘要一致。 |
| 靜態匯入 | 相機與方向權限呼叫數為零。 |
| 格網互動 | 格線可切換，選格顯示對應 cell ID，舊照片保留 image-only。 |
| 展示資料量 | 每張參考最多顯示 96 個淡色點；完整特徵數等於格內計數總和，選格數值與實際配對不受取樣影響。 |
| 環景接縫 | 0°／360° 等價方向與同批次重疊格網一致；由合成 worker 與幾何測試互相補充。 |
| 民眾預編譯模式 | 不請求原始照片目錄、不以原圖即時計算特徵，可顯示不含原照片的參考特徵圖。 |
| 手機與桌面 | 390／1280 CSS px 展開格網後無水平溢出。 |
| 資料與導引 | 真實資料檔不變、沒有後台修改請求、沒有自動抵達。 |

執行結果與截圖輸出至 `test-output/fishnet/`。只有 `report.json` 顯示 `passed: true` 才表示該次自動化測試通過；仍不代表真實手機權限、IMU 精度、現場準確率或雲端部署完成。

本次未入庫合成裁切圖在原版／Fishnet 都得到 90 組配對、90 個幾何有效點，且送入辨識器的像素相同。這說明 A/B 與索引流程可用；此樣本沒有顯示 Fishnet 優於原版，不可據此宣稱現場準確率改善。
