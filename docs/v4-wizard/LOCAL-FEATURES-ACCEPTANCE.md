# V4 局部特徵辨識驗證

日期：2026-09-07。本文件記錄本機驗證範圍；線上版本須另核對 Azure 部署與檔案。無現場準確率宣稱。

## 範圍

- 獨立 V4 ORB worker 和載入器。V3 發布頁面、主程式、CSS 與 worker 不變；共用路線元件僅新增 V4 可選資料注入入口，V3 預設載入流程不變。
- 工作台照片測試仍能即時計算；民眾端使用發布程序產生的二進位索引，不要求重傳、不改原照片或後台保存格式。原始資料不送往民眾手機。
- 改驗證可見局部特徵，而不是完整照片四角。維持至少 12 個幾何有效配對、有效比例至少 0.5、重新擬合後誤差檢查、來源與取樣畫面的特徵分布檢查。
- 相近的不同節點結果視為歧義；同一節點的重疊方向照片不互相排斥。多尺度中同位置的特徵不重複計票。
- 最長邊限制 420px，避免直式相機相較橫式參考照被不必要地放大；參考照片載入設有逾時與逐張錯誤摘要。
- 展開式診斷顯示配對點、局部區域、候選／未通過原因及可用／略過照片，不以百分比冒稱定位精度。
- 局部匹配不直接校準手機朝向。民眾端需人工面向下一地標後校正，且抵達仍需確認。
- 民眾端搜尋目前路段的起終點、沿途與同樓層直接相鄰節點；每輪上限 64 張，保留起終點照片優先，再交錯選取其他節點，顯示未納入數量。不是全場域重定位。
- 工作台與民眾端共用同節點連續確認函式，方向照片交替不重算；不同節點、失敗及逾 5 秒中斷重算。幾何匹配門檻未改。
- 民眾端新增收合診斷、照片範圍清單及共用配對圖。鄰近／中途節點候選不會移動位置，也不解鎖路段終點抵達。

## 可重跑測試

- `npm run test:ar-v4-partial`：分布／共線／歧義單元測試，以及真實 browser worker 的原圖、直式裁切、旋轉裁切、遮擋、無關圖、空白圖、跨節點同圖與同節點多圖測試。
- `npm run test:ar-v4-public`：搜尋範圍／上限／同節點累積單元測試，加上真實 ORB 連續辨識中途、鄰近及終點的瀏覽器測試；候選不自動抵達、局部匹配不自動設定朝向、明確校正後箭頭隨感測器變化，以及手機診斷面板 RWD。
- `npm run test:ar-v4-browser`：保存／校正／相機生命週期／路網及安全回歸；工作台新增匹配點與 390px 展開診斷面板檢查。
- `npm run test:ar-v4-wizard`：六大功能、環景批次與草稿恢復回歸。

所有測試寫入使用臨時 loopback 後台，沒有寫入真實本機／雲端場域。`test-output/` 下的報告和截圖不納入部署。

## 特徵包與連續方向回歸

- `scripts/ar-v4-feature-publisher.mjs`：以同一 V4 worker 的特徵抽取函式預先建立索引；Sharp 只在發布端解碼及縮放照片，串行限制解碼記憶體。不抓取任意外部照片網址。
- `npm run build`（Azure）與 `npm run build:ar-v4` 會自動產出 `assets/ar-v4-public/`。衍生輸出不提交 Git，以部署時的路網快照重新生成；本機後台按本機資料版本生成，不覆寫資料。
- 內容雜湊、演算法版本、節點 ID、尺寸、層級、特徵數與二進位長度驗證；錯誤資料不回退原圖。快取最多 64 組，下載並行上限 2。
- 瀏覽器測試封鎖原始照片目錄與 API、使用真實二進位索引完成 A/B/C 與鄰近地標匹配；持續方向變動 4.5 秒索引仍只初始化一次。
- 診斷收合時沒有 `toDataURL` 快照編碼；展開可顯示相機特徵。測試包含快取後封鎖特徵包網路、全包 503 時留在原頁、人工地圖操作與明確重試恢復。

## 限制

目前仍是圖像局部特徵與幾何模型，不是任意三維場景定位。重複紋理、強反光、大幅站位變化、視差、模糊或缺少可用照片可能失敗。既有八方向照片為正常透視投影，但不保證跨裝置／任意取景都能匹配。需要使用者的真實環景及手機實拍正反例，才能進一步調整與評估。
